# Glosario

| Término | Definición |
|---|---|
| **Producto** | Artículo o material que la empresa puede adquirir a través de un proveedor, con atributos como nombre, descripción y unidad de medida. |
| **Proveedor** | Empresa o persona externa que ofrece uno o varios productos a un precio determinado. |
| **Orden de Compra** | Documento generado por el sistema que formaliza la solicitud de uno o varios productos a un proveedor específico. |
| **Épica** | Historia de usuario de gran tamaño que agrupa varias funcionalidades relacionadas dentro de un mismo módulo. |
| **Historia de Usuario** | Descripción breve de una funcionalidad desde la perspectiva de un rol, expresada en el formato "Como \<rol>, quiero \<acción>, para que \<beneficio>". |
| **Criterio de Aceptación** | Condición específica, expresada en formato Dado-Cuando-Entonces, que debe cumplirse para considerar una historia de usuario como terminada. |
| **MoSCoW** | Técnica de priorización que clasifica los requisitos en Must have, Should have, Could have y Won't have. |
| **SPA (Single-Page Application)** | Aplicación web que carga una única página HTML y actualiza su contenido dinámicamente sin recargar el navegador. |
| **API** | Interfaz que permite la comunicación entre la SPA y el backend del sistema mediante peticiones HTTP. |
