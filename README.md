# Proyecto ERP - Documentación de Arquitectura

Este repositorio contiene la documentación de arquitectura del **Módulo de Compras** del Sistema ERP, desarrollado como parte del taller de ciclo de vida de desarrollo de software.

## Contenido

- **Backlog ágil**: gestionado en [Jira](enlace-a-tu-tablero-jira) — épicas, historias de usuario, criterios de aceptación y priorización MoSCoW.
- **Documentación de arquitectura**: siguiendo la plantilla [arc42](./arc42-template-EN-plain-markdownMP), disponible en la carpeta `arc42-template-EN-plain-markdownMP/`.
- **Diagramas**: ubicados en `arc42-template-EN-plain-markdownMP/images/`, incluyendo diagrama de contexto (C1), contenedores (C2), secuencia y modelo entidad-relación.
